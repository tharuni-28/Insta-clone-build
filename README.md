# 📸 Instagram Clone

A responsive Instagram-inspired social media web application built using **React.js and Firebase**.  
The project provides user authentication and core social-media functionality with a modern Instagram-style interface.

## ✨ Features

- 🔐 **User Authentication** using Firebase Authentication
- 🏠 **Home Feed** for displaying posts
- 📷 **Create and Upload Posts**
- ❤️ **Like Posts**
- 💬 **Comment on Posts**
- 👤 **User Profiles**
- ➕ **Follow / Unfollow Users**
- 🔥 **Firebase Backend Integration**
- 📱 **Responsive User Interface**
- ☁️ **Deployed using Vercel**
